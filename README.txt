STRATUS DIAGNOSTIC V5.3

What is new: Every successful scan also creates two user-friendly executive reports:
- ..._EXECUTIVE_SUMMARY.html: Open in a browser or print to PDF.
- ..._EXECUTIVE_SUMMARY.txt: Plain text for email, Teams, or tickets.

The summary ranks real local geometry API exceptions first, then link/coordination isolation leads, and it clearly shows scan coverage. It never claims a local scan proves Autodesk cloud translation will pass.

Installation: Replace script.py and bundle.yaml in your existing
Revit_Stratus_Diagnostic.pushbutton folder and click pyRevit > Reload.

Reports: Desktop/Revit_Stratus_Diagnostics (or Documents fallback).

Recommended first run: Deep scan + 250 fabrication parts.

Read-only; no model edits or automatic publish. Not runtime-tested inside Revit 2026.
